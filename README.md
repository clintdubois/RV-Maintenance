# RV Maintenance Documentation

Comprehensive maintenance, repair, and system documentation for RV vehicles and camper vans.

## Repository Structure

### Winnebago_View_2020D/
Documentation and maintenance logs for the Winnebago View 2020 (24D floorplan) motorhome.
- Battery replacement procedures
- Electrical system troubleshooting
- Charging system upgrades
- OBD scanner diagnostics

### Winnebago_View_2027R/
Documentation and troubleshooting guides for the Winnebago View 2027 (24R floorplan, referred to
locally as "27R" — see the naming note in that folder's README).
- Inverter, 12V fuse/breaker panel, and CZone digital switching system
- Troubleshooting guides (parasitic draw, gray tank sensor, awning) built with the reusable
  `scripts/troubleshooting_doc.py` template
- Wiring diagrams and operator's/component manuals

### Luna_Campervan/
Documentation and resources for Luna the campervan.
- How-to guides and operation manuals
- Rental planning and logistics
- Maintenance records
- Business documentation

### Systems/
Cross-vehicle RV system documentation and reference guides.
- **Battery Systems**: House batteries, chassis batteries, charging solutions
- **Electrical**: Wiring diagrams, troubleshooting, alternator/trickle charger upgrades
- **Appliances**: Furnace, water systems, refrigeration
- **Climate Control**: Heating/cooling systems, Truma heaters
- **Power Management**: Solar, inverters, shore power integration

### Projects/
Active and completed maintenance projects across all vehicles.
- Major system upgrades
- Repairs in progress
- Installation guides
- Lessons learned

## Usage

Browse by vehicle type in the top-level folders, or explore the Systems/ directory for cross-vehicle reference material. Each document includes maintenance procedures, diagnostic steps, and relevant specifications.

For questions or additions, refer to specific vehicle folders or the Projects/ directory for similar completed work.
